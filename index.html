System Diagnostic Reference

Troubleshooting Principles & Decision Matrix

Hardware Principles

  • Lack of LED indicators and fan movement indicates power circuit failure, exhausted battery, or adapter fault.
  • Functional LED and fans paired with working external video output pinpoints internal LCD panel or backlight failure.
  • Power LEDs active without display output on either internal or external monitor indicates memory (RAM) POST failure or motherboard logic fault.
  • Blue recovery screen (BSOD) confirms hardware power & video are functional, but system boot files or drivers are corrupted.
  • Rapidly blinking charger LED indicates short-circuit protection triggered within the power adapter or charging port.

Diagnostic Decision Matrix

SCENARIO 1:
IF (Power Symptoms = "No lights/fan") AND (Charger Light = "OFF or blinking")
THEN Status = "Power Supply / Adapter Failure"
RECOMMENDATION = "Test with an alternative wall outlet or replace the charger."
SCENARIO 2:
IF (Power Symptoms = "Screen black") AND (External Display = "Yes")
THEN Status = "Internal Display Panel Failure"
RECOMMENDATION = "Replace the laptop LCD screen assembly or internal display cable."
SCENARIO 3:
IF (Power Symptoms = "Screen black") AND (External Display = "No")
THEN Status = "RAM / POST Initialization Failure"
RECOMMENDATION = "Reseat or swap internal RAM modules."
SCENARIO 4:
IF (Power Symptoms = "Blue recovery screen")
THEN Status = "OS System File Corruption"
RECOMMENDATION = "Boot into System Recovery to perform startup repair."
